# Adding Products

All product information is stored in `assets/products.json`.

To add a product:
1. Copy an existing product object.
2. Give it a unique `id`.
3. Change its name, price, MRP, category, description, dimensions, material, weight, quantity, offers and features.
4. Add/update its image path if applicable.
5. Commit and push to GitHub Pages.

Do not edit `assets/js/app.js` when adding products.
